# 「パーツ分解」プラグイン

### [最新バージョンをダウンロード](https://github.com/Dolphin-kun/PartsSplitter/releases/latest)

## 概要
テキストや画像をパーツに分解する映像エフェクトです。  
テキストの分解や、立ち絵のバラシにも使えるかと思います。

## 使い方
1. アイテムを追加して、`加工`カテゴリーにある「パーツ分解」を選択して追加してください。

## 効果
### パーツ
表示させるパーツを指定します。

### 表示
#### デフォルト
デフォルトの順番でラベリングされます。

#### カスタム
順番をカスタムすることができます。

例: 1,2,3-4-5,6~9

|書き方|効果|
|-|-|
| , ( . ) |区切り|
|-|追加|
|~|範囲指定|

### 順番表示
ラベリングの順番を表示します。  
プレビューの再生時と出力時は表示されません。  
たまに範囲外から見切れることがありますが修正するか悩み中です(描画サイズが変わってしまうため)。

---

### しきい値
つながりを検知してラベリングしていて、その強度をしていします。
